# Graph-v1 개발 결과

특징점 사이 거리·방향·상대 방위의 일관성을 각 정합 가설에서 평가하는 별도 후보다. 기존 v2는 보존한다. DB별 파라미터나 이미지 ID를 사용하지 않는다. 설계: `protocol/graph-v1-design.json`.

잡음 시드가 다르면 동일 픽셀에 대한 직접 비교가 아니다. 동일 시드 반복이 필요하다. 모두 이미 노출된 개발 데이터로 독립 검증이 아니다. DB2 clean에는 특징 추출 1/80 실패가 남아 있다.

## 선택 규칙

`fp_plan DB iType NEW_PLAN seed enroll_rule genuine_rule impostor_rule`

각 규칙: `first`, `all`, `random:N`, `indices:1,3`. 비교에는 `none`도 지원한다. 진짜는 등록 이미지별 자기 자신을 제외하고, 가짜는 등록 이미지별·다른 지문별로 선택한다. 비복원 추출이며 부족한 장수·없는 순번은 오류다. GUI에도 세 규칙과 입력을 연결했다.

정합 분석은 원래 DLL 이름 `fingerprint_graph.dll`로 graph-v1을 선택한다. 이름 변경은 지원하지 않으며 저장 점수와 다르면 분석을 거부한다.

독립 데이터, 더 강한 미관측 잡음, 낮은 FMR의 신뢰구간, 처리 시간 평가가 필요하다. 인증 수준 달성을 주장하지 않는다. GUI 실제 클릭과 깨끗한 PC 설치 검증은 미완료다.
